📱 아이폰 홈 화면 추가 방법

  1. iOS Safari 브라우저 하단 중앙의 [공유] 버튼 (네모에 화살표 아이콘) 클릭
  2. 메뉴를 아래로 스크롤하여 ['홈 화면에 추가'] 선택
  3. 우측 상단 [추가] 클릭
  4. 아이폰 바탕화면에 생성된 AI YouTube 앱 Icon으로 즉시 실행!
